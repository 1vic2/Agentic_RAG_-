# AgenticRAG 可靠性完善方案（待确认）

## 目标与范围

面向本地使用和面试演示，完善现有 RAG 主链路。沿用 FastAPI、Vue、ChromaDB、LangGraph 和可选 Neo4j/Tavily，不引入新的外部基础设施。本轮重点是行为正确、故障可见、测试可重复，不承诺未评测的准确率或性能提升。

现有工作区包含用户未提交修改；实现时以当前文件为基础，保留这些修改。测试使用临时目录、隔离数据库和模型替身，不修改现有知识库数据，不读取或输出 API 密钥。

## 方案比较

1. 仅修明显报错：改动最少，但会话、删除残留和重复索引仍影响日常使用。
2. 完善问答可靠性和数据一致性（推荐）：修复关键边界、补测试、同步文档，形成可演示的完整流程。
3. 扩展完整自主 Agent：增加问题拆解、反馈检索与事实核验，模型调用成本和评测范围明显增加，安排在基础链路稳定之后。

## 一、会话与流式响应

- 将前端会话 ID 作为请求的明确参数，切换、新建及刷新后都使用对应会话 ID。
- 后端 SSE 编码器不保存共享的会话状态；每个完成事件明确携带本次请求 ID。
- SSE 解析独立为可测试模块，保留不完整行和事件，支持 LF/CRLF、跨网络块 UTF-8、连续多个事件及多行 data。
- 请求失败、error 事件和无 done 的异常断流给出可见提示；所有退出路径释放读取器并恢复发送状态。
- 流式请求绑定发起时的会话，避免用户切换页面或会话后把答案写入另一个会话；提供取消当前生成的能力。
- 正确传递最近完整用户/助手历史；流式和非流式接口使用一致的历史构造逻辑。
- 用 Python 标准库 SQLite 保存后端会话消息，记录角色、答案、证据和时间，支持重启后恢复上下文。历史窗口有明确轮数及长度上限。
- 本轮不增加基于 LLM 的追问改写，文档明确当前检索仍以当前问题为查询。

验收：两个交错请求不串 ID；两段独立会话不共享历史；刷新后可继续原会话；任意分包不丢字；失败或取消后能再次发送。

## 二、工具执行与图谱证据

- 修复工具循环边界，确保合法工具按计划各执行一次。
- 路由结果必须是字符串数组，按本次实际允许工具过滤并去重；关闭联网时不能执行 web；异常或空计划回退到 vector。
- 统一 vector、graph、web 的证据结构为 id、text、source、score，必要时增加类型字段区分评分来源。
- 图查询传入 kb_id，使用参数化条件隔离知识库；把实体关系记录转换成可用于生成的文本证据。
- 工具失败记录清楚的状态，保留其他工具的可用证据；无证据时明确说明资料不足。
- 保持当前工具路由架构，不把这一轮描述为完整的自主推理 Agent。

验收：1/2/3 个工具计划全部执行；禁用 web 后异常模型输出也无法启用 web；图证据能进入生成提示词；指定知识库的图查询不读取其他库。

## 三、索引与删除一致性

- 文档向量显式保存 type=document、kb_id、source 和 chunk_index；采用稳定标识，替代基于集合条数生成 ID。
- 按文件更新索引，先成功解析和生成向量，再写入新片段并清理该文件的过期片段；重复索引不持续增长。
- 解析、编码失败保留该文件旧索引并报告失败；不声称跨多批 Chroma 写入具有数据库事务保证。
- 删除文档同步清理其向量。文档变更使旧图谱失效，避免继续将过期关系作为当前证据。
- 图谱删除、知识库删除统一协调本地图、实体向量及 Neo4j；外部数据库不可用时明确报告未完成清理，保留可重试状态。
- 兼容已有缺少 type/chunk_index 的记录，在用户触发相关文件重建时逐步替换，不启动全库清空或自动迁移。
- 统一前后端文件支持列表；上传和删除验证路径边界，拒绝目录逃逸及不支持格式。
- 同一知识库的变更串行处理，避免单进程并发更新互相覆盖；多进程跨存储事务不在本轮保证范围。

验收：重复索引条数稳定；文档缩短后旧片段消失；更新失败原索引保留；删文件后检索不到其内容；重建一个库不影响其他库。

## 四、运行体验与文档

- 索引和图谱构建的同步重工作移出事件循环，现阶段使用线程卸载；不引入任务队列。
- 修正模型离线配置行为，允许明确选择本地模型或在线获取，避免代码强制离线。
- 补齐直接使用的依赖，区分基础解析与可选复杂格式解析；对解析依赖缺失给出清楚错误，不把二进制文件当纯文本索引。
- 修复涉及页面的 TypeScript 构建问题，错误状态可见。
- 更新 README：真实能力、启动方式、配置项、测试命令和当前限制。

## 验证方法

先为已知问题编写失败回归测试，再进行对应修复。

- 后端：会话隔离与持久化、工具路由、图证据格式、索引幂等、删除和路径边界。
- 前端：SSE 分包与错误/取消、会话切换及消息归属；运行类型检查和生产构建。
- 集成：临时 Chroma 数据目录验证索引生命周期；外部 LLM、Tavily 和 Neo4j 使用明确替身，验证调用参数与错误传播。
- 实际外部服务联调仅在可用环境中进行，并与离线测试结果分别报告。
